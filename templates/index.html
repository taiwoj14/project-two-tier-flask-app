About This Project

This is a two-tier Flask web application demonstrating a scalable architecture where the frontend interacts with a backend service and database.

The application is containerized using Docker and managed with Docker Compose to run multiple services (Flask and MySQL) in a unified environment. It is deployed on AWS EC2 and integrated with a CI/CD pipeline for automated build and deployment, showcasing hands-on experience in cloud and DevOps workflows.

Tech Stack: Flask, Python, MySQL, Docker, AWS EC2, Jenkins, CI/CD
